# Hola, soy Daniel Gallardo (`@Daniii205`) 👋

Desarrollador de Aplicaciones Multiplataforma en formación (**2º DAM**) y Técnico en Sistemas Microinformáticos y Redes (**SMR**). Me apasiona crear software funcional, diseñar interfaces limpias centradas en la experiencia de usuario (UI/UX) y resolver problemas técnicos combinando código y sistemas.

---

### 🚀 Lo que sé hacer

* **Desarrollo Multiplataforma y de Escritorio:** Creación de aplicaciones robustas en **Java** y **C# (.NET / Windows Forms)**, trabajando con programación orientada a objetos, gestión de procesos, manejo de ficheros (I/O) y estructuras de datos personalizadas.
* **Desarrollo Web y Diseño UI/UX:** Maquetación y desarrollo de aplicaciones web interactivas y responsive con **HTML5, CSS3 y JavaScript**, cuidando la estética, el diseño de interfaces modernas y el despliegue en **GitHub Pages**.
* **Desarrollo Móvil:** Construcción de aplicaciones nativas para Android utilizando **Android Studio**.
* **Bases de Datos:** Diseño, consulta y administración de bases de datos relacionales con **MySQL Server**.
* **Sistemas y Redes:** Administración de entornos **Linux (Ubuntu)** y **Windows**, virtualización (**VirtualBox**) y configuración de infraestructura de red.
